# 格局裝修設計

純前端的格局裝修設計工具：在 2D 平面圖上擺放傢俱、拆改牆體、測量尺寸，一鍵切換到 Three.js 3D 場景，可以鳥瞰，也可以第一人稱漫遊。應用由 `index.html` 與 `layout-editor.js` 組成，無需構建，開啟即用。

## 手機與線上使用

GitHub Pages 網址：https://saint20120818-design.github.io/floorplan3d/

手機可直接以 Safari 或 Chrome 開啟，橫向使用較容易操作；可從瀏覽器選單加入主畫面。3D 首次載入需網路連線。

方案自動儲存在各裝置、各網站的瀏覽器本機空間，不會跨裝置同步。要把電腦上的配置帶到手機，請從「檔案」匯出方案 JSON，將檔案傳到手機，再從手機網頁「檔案」匯入。GitHub Pages 發布的是程式與預設格局，不會上傳瀏覽器內的個人方案。

匯出檔名帶時間，請傳送最新下載的 JSON。匯出會先套用格局／文字面板內的有效欄位，並包含家具、格局修改、新增牆窗、文字位移、測量、顯示單位與圖層設定。匯入後會重新適應畫面，並顯示檔名與家具數量；仍支援同格局的舊版 JSON。兩台裝置都應先重新整理至最新版本，再進行匯出／匯入。

部署設定：GitHub Pages 從 main 分支根目錄發布。更新並推送 main 後，Pages 會重新發布。

## 功能

**2D 平面佈置**
- 按原始格局 1:60 / 1:100 比例顯示，尺寸單位可切換 cm／mm
- 從左側傢俱庫拖入 60 餘種傢俱家電（臥室、客廳、餐廚、衛浴、家電、書房休閒）
- 拖動移動、旋轉（Shift 自由角度）、調整尺寸，貼牆自動吸附
- 測量工具（靠近牆面自動吸附，Shift 鎖定水平 / 垂直）
- 拆改非承重牆，承重牆單獨標示
- 圖層開關：尺寸標註、房間名、傢俱、網格、承重牆

**3D 場景**
- 鳥瞰、斜視、俯視多種視角，點選房間列表可飛到對應房間
- 漫遊模式：桌面端 WASD + 滑鼠，觸屏裝置用虛擬搖桿，可以點門開關
- 全高牆 / 剖切牆切換，日照時間滑塊，夜景燈光
- 精細傢俱模型：櫃門分縫與拉手、軟包床頭、帶環境反射的金屬與陶瓷材質等
- 在 3D 中也能選中、拖動傢俱，與 2D 方案即時同步

**方案與統計**
- 房間面積與套內使用面積自動統計
- 為每個房間更換地面材料（木地板、地磚、大理石、水磨石、地毯等），按面積加 5% 損耗估算造價
- 復原 / 重做，方案自動儲存在瀏覽器本地
- 繁體中文 / English 介面切換（頂欄右側按鈕，預設繁體中文，選擇會記住）
- 匯出 PNG 圖片，匯出 / 匯入方案 JSON

## 快速開始

```bash
git clone <倉庫地址>
cd <倉庫目錄>
```

然後直接用瀏覽器開啟 `index.html`。也可以起一個本地靜態伺服器：

```bash
python3 -m http.server 8000
# 訪問 http://localhost:8000
```

> Three.js 通過 jsDelivr CDN 載入，首次開啟 3D 場景需要聯網。

## 快捷鍵

| 按鍵 | 作用 |
| --- | --- |
| `T` | 切換 2D / 3D |
| `V` / `M` / `X` | 選擇 / 測量 / 拆改牆體 |
| `R` / `Shift+R` | 選中傢俱順時針 / 逆時針旋轉 90° |
| `Delete` / `Backspace` | 刪除選中傢俱 |
| `Ctrl/⌘ + D` | 複製選中傢俱 |

| `F` | 適應視窗 |
| `+` / `-` | 放大 / 縮小 |
| `[` / `]` | 展開 / 收起左側傢俱庫、右側面板 |
| `Shift + F` | 全螢幕 |
| `Esc` | 取消當前操作 |
| 漫遊：`WASD` / 方向鍵，`Shift`，`E` | 移動，快走，開關門 |

## 技術棧

- 原生 HTML / CSS / JavaScript，無框架、無構建步驟
- 2D 平面圖用 SVG 繪製
- 3D 場景用 [Three.js](https://threejs.org/) r160（OrbitControls、PointerLockControls、RoundedBoxGeometry、RoomEnvironment、CSS2DRenderer）
- 資料儲存在 `localStorage`

## 自定義格局

格局資料寫在 `index.html` 裡：

- `BASE_ROOMS`：原始房間多邊形、名稱、預設地面材料
- `BASE_WALLS` / `BASE_WINS` / `BASE_DOORS` / `BASE_SLIDES`：原始牆體、窗洞與門
- `MATS`：地面材料名稱與單價
- `LIB`：傢俱庫（型別、名稱、預設尺寸、顏色）
- `buildFurniture()`：各類傢俱的 3D 模型

改這些資料就能換成自己的格局。

### 目前預設格局與換算

已依第二張參考圖（原單位 cm）重建兩房、更衣室、兩衛浴、廚房、客餐廳及陽台。2D 與 3D 共用相同幾何資料。

預設方案為 2026-10-01 匯出的配置，寫在 `index.html` 的 `DEFAULT_PLAN`（含家具、格局修改、新增窗戶、文字位置與測量）。首次開啟（瀏覽器沒有存檔）及「重置為預設方案」都會載入它；要更換預設，把新匯出的 JSON 內容（去掉 exportedAt、display）貼到 `DEFAULT_PLAN` 即可。`defaultState()` 仍是只含廚衛設備的原始空白格局，供測試使用。

- 頂部「尺寸」可切換 cm／mm，包含圖面標註、測量、家具庫、家具尺寸與位置輸入；內部資料與 JSON 固定使用 mm。
- 頂部「面積」可切換 m²／坪。1 坪 = 400/121 m²，1 m² = 0.3025 坪；總覽同時提供兩種數值。室內與戶外分開統計，挑空／管道間不生成樓板，也不計入面積或地坪造價。
- 金額顯示 NT$，把原材質示範單價視為 CNY/m² 後乘匯率換算。右側總覽「地面材料估算」可修改匯率；預設 4.779，來源為[台灣銀行 2026/09/30 即期賣出](https://rate.bot.com.tw/xrt/quote/ltm/CNY/spot/1)，非即時匯率，也不是台灣施工報價。面積切成坪後，材質單價同步顯示 NT$/坪。
- 顯示單位與匯率會記住；估價含 5% 材料損耗。

主要淨尺寸依圖：臥室 335×245 cm、主臥室 245×350 cm、更衣室 195×250 cm、客廳 270×350 cm、餐廳 235×255 cm、廚房 155×280 cm，前陽台寬 325 cm。牆厚約 10–15 cm、未標示門窗與外側平台深度、層高 2.8 m 為估算；陽台欄杆高依圖採 120 cm。黑色構件按圖保留，結構屬性未經確認。面積為此模型計算，非權狀面積。

新格局使用獨立儲存鍵，保留舊格局的瀏覽器資料。本格局 JSON 含 planId；匯入時拒絕不同格局的方案，避免家具位置與拆牆編號錯套。檔案選單的「重置為預設方案」會恢復為上述 `DEFAULT_PLAN`。已經有存檔的瀏覽器不會自動換成新預設，需按一次「重置為預設方案」。

### 在介面編輯格局

1. 點頂部「格局編輯」，或選取房間後點右側「修改範圍／刪除」。
2. 從圖上或右側清單選取房間／平台、牆壁／欄杆、窗戶、房門、拉門。
3. 修改左上角 X／Y、水平／垂直長度，按「套用修改」。欄位跟隨 cm／mm；房門還可設定開口方向、鉸鏈端點與開門方向。
4. 「刪除此物件」保留可恢復紀錄；清單仍找得到已刪除物件。「恢復此物件」保留原編輯尺寸，「還原此物件」回到原始尺寸與位置。Ctrl/⌘＋Z 可復原。

房間／平台調整的是地板範圍，牆、柱、門窗、欄杆與家具各自獨立，需分別修改。修改原有門窗位置後須調整相鄰牆段以留下洞口；新增窗戶會依窗戶範圍自動在 3D 牆體開洞。目前不會自動連動相鄰房間；面積按各空間範圍加總，請避免重疊。

### 直接拖曳移動與改尺寸

在 2D 點「格局編輯」後，可直接拖曳房間、平台、牆、窗、門或拉門移動，也可拖曳選取物件的白色十字把手。牆與門窗兩端會顯示橘色把手，拖曳其中一端可拉長或縮短，另一端及厚度保持不變；房間／平台使用四個角點調整長寬。精確厚度及座標仍可用右側欄位設定。

拖曳以 1 cm 為步進，按住 Alt 可微調至 1 mm；Shift 鎖定水平／垂直移動。拖動時圖面、尺寸與右側數值即時更新，放開即儲存並同步 3D，一次拖曳只需一次 Ctrl/⌘＋Z 即可復原。Esc、觸控取消或轉為雙指縮放會取消尚未完成的格局拖曳；拖曳空白處仍可平移畫布。移動牆不會自動帶著窗戶或其他獨立元件移動。

### 移動重疊文字

上方「家具尺寸」開關可在每件家具旁顯示寬度、深度的尺寸線及數字，跟隨家具移動、旋轉、縮放與 cm／mm 切換。預設關閉以避免擁擠；開啟後，兩個尺寸數字也能在「文字位置」模式分別拖曳。

2D 上方「文字位置」模式可分別拖曳房間名稱、面積／坪數、尺寸數字、家具名稱與挑空標籤。拖曳只修改標籤在平面圖上的偏移，尺寸線與實際格局不變，也不影響 3D 標籤。文字疊在一起時，從右側「選擇文字」清單選取，再拖橘色虛線框，或輸入水平／垂直位移（支援 cm／mm）。「還原此文字」和「還原全部文字位置」可重設，且支援復原。放開即自動儲存，位置存於 labelOffsets，隨方案 JSON 匯出／匯入及 PNG 匯出保留。Esc 可取消尚未完成的拖曳。

尺寸線端點的斜線是刻度標記；已縮短，並限制放大時的畫面大小。可用上方「尺寸」按鈕隱藏整個尺寸圖層。

### 新增牆壁與窗戶操作

- 點「格局編輯」→右側「＋ 新增牆壁」。預設在所選物件中央建立長 200 cm、厚 12 cm 的隔間牆；輸入 X／Y 與水平／垂直長度，再按「套用修改」。直向牆將水平長度設為牆厚、垂直長度設為牆長。
- 先選取完整牆壁，再點「＋ 新增窗戶」，會建立沿牆置中的窗戶，預設寬 120 cm（牆較短時配合牆長）、厚度跟隨牆厚。未選牆時建立獨立窗戶，需自行調整位置及厚度使其覆蓋牆面。
- 新增窗戶的窗台高 90 cm、窗頂高 240 cm。新增窗戶範圍會在 3D 牆體開洞；移動、刪除、復原會同步重建洞口。需讓窗戶完整涵蓋牆厚，且避免窗戶互相重疊。牆和窗的位置仍各自獨立，移動牆後需一起調整窗戶。
- 新增物件也支援 cm／mm、刪除／恢復、Ctrl/⌘＋Z、自動儲存及 JSON 匯出／匯入；資料存放在 layoutAdded，後續修改存放在 layoutEdits。重新整理即可看到新增按鈕。

編輯結果會同步到 2D、3D、面積與地坪估價，保存在原方案的 layoutEdits 中，也會隨 JSON 匯出／匯入。原始 BASE_ROOMS、BASE_WALLS 等資料保持不變，既有方案沒有 layoutEdits 時會使用原始格局。請將 layout-editor.js 與 index.html 放在同一個資料夾。

仍未提供圖片自動建模。更換原始格局時應同步更新 PLAN_ID。

驗證：執行 node tests/layout.test.cjs，另以瀏覽器檢查 2D／3D、單位切換與家具尺寸輸入。
